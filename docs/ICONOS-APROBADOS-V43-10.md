# Hunter System V43.10 — Iconos PNG aprobados

La fuente de diseño es la lámina `biblioteca_de_íconos_hunter_system.png` aprobada por el usuario. `tools/install_hunter_reference_icons.py` descarga la imagen de referencia y recorta los símbolos luminosos existentes, sin redibujarlos, generando **40 iconos PNG diferentes y 29 alias funcionales**, todos de 128×128 píxeles con canal alfa. Los fondos rectangulares se retiran por una máscara rasterizada. El script original V43.9 continúa aportando los 8 paisajes PNG, pero su biblioteca anterior de iconos se reemplaza.

Tamaños nativos (dp): barra inferior 29→38 y altura de barra 75→86; rail 30→39; lateral 42→56; cabecera del menú 48→60; rutinas 53→64 y portadas 64→74; metas 40/44/52→50/53/62; estadísticas 43/46/48/59→52/57/58/70. Las áreas táctiles siguen presentes y el menú continúa siendo desplazable.

No se cambian las condiciones para activar misiones especiales; en caso de incompatibilidad con el perfil el botón seguirá deshabilitado. Los 2000 SVG de ejercicios, las tres imágenes de jefes, los 8 fondos PNG y el estado local de usuario se conservan. Es una versión preliminar, pendiente de inspección visual en Android real.
